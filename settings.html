👥 读成员样本

和「拓群」是两个独立动作：这里勾选的平台才会去读成员名单；上限 0 = 本轮读完（受预算兜底）。Steam 与 Telegram 风控较低，可以把上限设得很高。
平台本轮读取每轮上限预算(分钟)说明
说明：上限 0 表示「本轮不限，读到没有待采为止」；预算到点会提前停。Telegram 建议 3 分钟/群，Steam 15 分钟/群（全量 XML 分页）。

📈 关键词与 AI 热点

按平台分别统计有效搜索：连续 3 个不同轮零结果休眠 24h，再 3 轮休眠 7 天；错误/未知结果不计入；保护词与手工淘汰优先；全部休眠时本轮不回退旧词。AI 每周只依据近期「有日期、有来源」的聚合信号，最多给 5 条建议，必须人工应用，可按批回滚。
平台关键词状态有效轮命中/零/错误连续零休眠至操作
保护 = 不自动休眠；淘汰 = 不再参与搜索，需手工恢复；恢复 = 清除休眠/淘汰并重新参与排序。全休眠不会退回旧词，平台会如实显示无可搜词。
AI 周报策略与预算
默认规则：连续零 3 轮 → 24h；再 3 轮 → 168h（可在 config.kw_evolve 调整）。不会因为某个平台全休眠而回退旧词。
